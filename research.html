Current Projects

01LLM Tutoring

Reliable Feedback for Multiple Solution Paths

How can a tutoring agent recognize that a student's unexpected step is still correct?

This project evaluates LLM feedback in propositional logic using knowledge-graph-derived ground truth. It distinguishes optimal steps, valid alternatives, and incorrect reasoning so that feedback quality can be measured where adaptive tutoring matters most.

Focus
Step-level feedback evaluation
Methods
Knowledge graphs, benchmark design, LLM evaluation

02Multi-Agent AI

When Verification Helps—and When It Hurts

Does adding a second agent actually make tutoring feedback more reliable?

This work studies role-specialized tutoring pipelines in which one agent generates feedback and another verifies it. The project investigates how upstream quality, problem complexity, and agent roles affect the final pedagogical response.

Focus
Multi-agent feedback pipelines
Methods
Controlled experiments, error analysis, proof-state benchmarks

03Computing Education

Responsible LLM Integration in Classrooms

What do teachers and students need for LLM tools to support—not displace—learning?

This research synthesizes evidence about student-facing LLM tools and develops teacher-informed guidance for classroom adoption. It connects technical design decisions with pedagogy, assessment, and responsible implementation.

Focus
Student-facing tools and teacher practice
Methods
Systematic review, interviews, surveys, framework development
